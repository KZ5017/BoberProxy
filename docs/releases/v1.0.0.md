# BoberProxy v1.0.0 — First Stable Release

BoberProxy connects command-line testing tools to stateful Burp Proxy workflows. It transforms selected payloads, sends requests built from templates and can return the response from a separate result page to the tool.

## Highlights

- Request Template and optional CheckPage workflow, with raw payload handling and optional custom Python transformations.
- Extension-owned target scope for one origin and an optional path prefix; managed cookie and CSRF state is reset when that scope changes.
- Guarded redirect following, response logging and filtering, and a resizable Python editor with the bundled RSyntaxTextArea library.
- Stabilization and regression evidence, including actual Burp/HTTP loopback tests in the recorded environment.

## Installation

1. Download `BoberProxy-v1.0.0.zip` from this release and extract it, keeping `BoberProxy.py` next to `lib/`.
2. Obtain a **Jython standalone 2.7.4 JAR** separately; it is not bundled. In Burp **Settings → Extensions → Python environment**, select that JAR.
3. In **Extensions → Installed → Add**, choose **Python** and select the extracted `BoberProxy.py`.
4. In the BoberProxy tab, configure **BoberProxy scope**, fill in your Request Template and enable template injection. See the [README](https://github.com/KZ5017/BoberProxy/blob/main/README.md) for a complete first request and CheckPage setup.

## Known limitations

- Custom code runs with Burp's Jython/Java permissions and is not sandboxed; timeouts cannot reliably terminate arbitrary Python/Java work or pathological Java regexes.
- Scope is one origin plus an optional path, independent of Burp Target scope. It is not a firewall or a full browser cookie jar. An out-of-scope redirect is not followed; an eligible in-scope CheckPage can continue.
- The recorded integration environment is Burp Suite Community 2026.10.1, Jython 2.7.4, Java 26.0.2 and Windows 11. Other combinations and full HTTP/2 behavior are not established by the recorded tests.
- The complete K11 long-run load suite predates the later Target Scope change; its attribution and baseline limits remain documented.
